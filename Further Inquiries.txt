Custom concept

- Type trait requirement
template <typename T> 
concept [custom_concept] = std::type trait<T>

- Argument operation type requirement
- checks for type syntax, not actual operation
template <typename T> 
concept [custom_concept] = requires (arg list){
    arg..action();              // evaluates only syntax
}

- then usage is same
template <typename T> 
requires [custom_concept]<T>

Nested requirement
- Argument operation evaluation requirement 
template <typename T> 
concept [custom_concept] = requires (arg list){
    arg..action();
    requires arg..action();     // evaluates the action for true
}

Compound requirement
- check for exception
template <typename T> 
concept [custom_concept] = requires (arg list){
    {arg..action()} -> (optional: noexcept) std::[conversion];
}

Combine concepts
- using boolean operation AND:&& and OR:||
template <typename T> 
requires [concept1]<T> [BOOLEAN_OPERATION] [concept2]<T>        // combined requirement

    a..b..;

Ch 18 Inheritence
note: By Inheritence we can only make the derived class constrained, not relaxed

define [base class]
class [base_class];   // forward declaration?

class [derived_class]: [Inheritence_Contstraint] [base_class]{
};

[Inheritence_Contstraint] = public|protected|private

friend class/function
- has access to private members of derived class
- no access to base class

public Inheritence - derived class will have access to public and protected members
(no change in derived class member access design)
public -> public
protected -> protected
private -> private

protected Inheritence - derived class will have access to public and protected members?
public -> protected
protected -> protected
private -> private

private Inheritence - derived class will have no access to base class members
public -> private
protected -> private
private -> private

Base Class  |   public Inheritence  | protected Inheritence |   private Inheritence
-----------------------------------------------------------------------------------
public      |   public              |   protected           |   private
protected   |   protected           |   protected           |   private
private     |   private             |   private             |   private

class           |   public              |   protected               |   private
access          |   object/external     |   only class function     |   only class function
inheritence     |   object/external     |   only class function     |   only base class function
